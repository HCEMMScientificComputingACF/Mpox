Mpox simulation studyAll the details of the study can be found in the paperJ. M. Benke, F. Nedényi, M. Szalai, G. Röst. Risk of evolution driven population wide emergence of mpox: the paradoxic effect of moderate interventions.Scripts:	mpox.py - contains all the objects and functions for the simulation and visualisation,	mpox_1_plot.py - create and plot a trajectory with SEIR dynamics and R0 values and with transmission chain graph,	mpox_2_detmut.py - simulation study for the deterministic mutation case (varying the value of n),	mpox_3_stochmut.py - simulation study for the stochastic mutation case (varying the value of sigma),	mpox_4_intlevel.py - simulation study for interventions
